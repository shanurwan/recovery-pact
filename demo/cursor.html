The five tools

Everything an incident review needs, inside the IDE

How it was built

Spec first, rules always on, scoped commits

The spec

A written spec defined the five tools, the data they read and what “done” means. Cursor's agent, on Grok 4.7, built the server, its tests and its docs from it, then used the tools itself to produce the transcript above.

The rules

An always-on project rule keeps every Cursor session inside the product's safety model: tools are read-only, published results are evidence and never edited, secrets are never read, and only its own files are committed.

The result

Three conventional commits co-authored by Cursor Agent. The server is registered for the workspace, so opening the repo in Cursor makes the five tools available.
