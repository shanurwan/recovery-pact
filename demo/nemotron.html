Why a DGX Spark

Incident data should not leave the building

A recovery agent reads exactly what companies guard most: which sessions touch payments, which customers are failing, whether the financial close is running. With open Nemotron weights the whole pact can run on-premises. NVIDIA rates DGX Spark for local inference on models up to about 200 billion parameters, which covers the Lightning and Super classes we benchmarked here. Finding 3 shows how much of the work a small model can carry.

Our runs used the hosted NVIDIA NIM API. Running on a DGX Spark is the next step, not something we have measured.

INFERENCE_MODE=nemotron NEMOTRON_MODEL=nvidia/nemotron-3.5-lightning-30b-a3b \
